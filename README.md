# 📚 Manual de Uso Git

Esta seccion contiene algunos comando basicos y algunos procedimientos que se utilizan
para trabajar con el control de versiones git

## 🔧 1. Configuración inicial

### Verificar la versión de Git

```bash
git --version
```
### Configurar un nombre de usuario

```
git config --global user.name "Tu Nombre"
```
### Configurar el correo 

```
git config --global user.email "tu@email.com"
```

## 🔧 2. Como crear un repositorio 

### Entrar ala carpeta del proyecto 

```
cd nombre-del-proyecto
```

### Inicializar Git 

```
git init
```
